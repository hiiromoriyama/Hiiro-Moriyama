X-ray Characterization of Hydrogen Embrittlement

Select a model to launch an interactive simulation environment where different material conditions can be explored in the context of hydrogen embrittlement (HE). Each model loads with parameters such as microstructure, hydrogen concentration, and strain, allowing you to adjust them in real time and observe how the system responds.

I started this project while trying to explain my work to friends and realised how hard it is to picture what’s actually going on, which led me to build these interactive visualisations. They’re based on real physics, but the focus is on making things intuitive and visual rather than quantitatively accurate.
